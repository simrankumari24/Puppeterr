## Interpreting the Output

### When a Patch Gets AUTO_APPROVED:

```json
{
  "patch_id": "C",
  "decision": "AUTO_APPROVE",
  "aggregate_score": 850,
  "changed_lines": 45,
  "reasons": [],
  "constraints": {
    "score_ok": true,      // >= 800
    "diff_ok": true,       // < 150 lines
    "dependency_ok": true,
    "license_ok": true,
    "env_ok": true,
    "has_blockers": true   // No blocker issues
  }
}
```

### When Applied Successfully:

```json
{
  "patch_id": "C",
  "status": "applied",
  "tests": {
    "status": "passed",
    "command": "npm test",
    "exit_code": 0
  },
  "commit_output": "[main abc1234] [auto-improve] apply patch C",
  "pr": {
    "status": "opened",
    "stdout": "Created pull request #123"
  }
}
```

### When Blocked by Policy:

```json
{
  "patch_id": "D",
  "decision": "HUMAN_REVIEW_REQUIRED",
  "aggregate_score": 900,  // High score but...
  "changed_lines": 200,    // ... exceeds max_diff_lines
  "reasons": [
    "Diff too large (200 lines)"
  ],
  "constraints": {
    "score_ok": true,
    "diff_ok": false,      // FAILED
    "dependency_ok": true,
    "license_ok": true,
    "env_ok": true,
    "has_blockers": true
  }
}
```

## Tracking Changes Over Time

Save reports from each run:

```bash
# After each pipeline run:
cp -r auto-improve/reports auto-improve/history/run_$(date +%s)/

# Analyze trends:
for run in auto-improve/history/*/; do
  APPLIED=$(jq '.results | map(select(.status=="applied")) | length' $run/apply_log.json)
  echo "$(basename $run): $APPLIED patches applied"
done
```
