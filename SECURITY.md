# Security Policy

## Supported Versions
This project is actively maintained. Only the latest version on the `main` branch receives security updates.

| Version | Supported |
|--------|-----------|
| main   | ✔️ |
| older  | ❌ |

## Reporting a Vulnerability
If you discover a security issue, please report it responsibly.

- Email: **Naimish.sah@gmail.com**
- Subject: **Security Report – [Short Description]**
- Please include:
  - steps to reproduce  
  - expected vs actual behavior  
  - potential impact  
  - logs, screenshots, or proof‑of‑concept (if available)

You will receive an acknowledgment within **48 hours** and a full response or fix plan within **7 days**.  
Confirmed vulnerabilities will be patched as quickly as possible.  
If a report is declined, an explanation will be provided.

Thank you for helping keep this project secure.
